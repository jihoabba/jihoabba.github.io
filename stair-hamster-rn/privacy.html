햄찌는 영차영차

개인정보 처리방침

시행일: 2026년 9월 26일

햄찌는 영차영차(이하 ‘앱’)는 러닝 기록을 기기 안에서 안전하게 보여 주기 위해 필요한 정보만 사용해요. 이 방침은 앱이 어떤 정보를 읽고 어디에 보관하는지 설명해요.

읽는 건강 정보

사용자가 HealthKit 권한을 허용하면 Apple Watch 기본 운동 앱이 기록한 러닝 운동을 읽어요. 읽는 항목은 다음과 같아요.

  • 운동 시작·종료 시각, 운동 시간, 거리와 운동 중 러닝 속도
  • 실내·야외 여부
  • 평균·최대 심박수와 운동 중 심박 변화, 활동·휴식 에너지(기록에 있을 때)
  • 러닝 파워, 보폭, 지면 접촉 시간, 수직 진폭과 운동에 기록된 누적 상승 고도(기록에 있을 때)
  • 운동 출처의 이름과 앱 식별자

앱은 HealthKit에 건강 데이터를 쓰지 않아요. 위치, GPS, 경로, 연락처, 사진 보관함 전체를 읽지 않아요. 공유 카드 이미지를 저장할 때만 사용자가 누른 동작에 따라 사진 추가 권한을 요청해요.

보관과 이용

러닝 기록과 계산된 씨앗, 소품, 착장은 기기의 로컬 SQLite 데이터베이스에 보관해요. HealthKit 권한은 선택 사항이며 iPhone의 설정 → 건강 → 데이터 접근 및 기기에서 언제든지 취소할 수 있어요. 권한을 취소해도 이미 앱에 저장된 로컬 기록은 자동으로 삭제되지 않아요.

앱은 건강 정보를 개발자, 분석 서비스, 광고 네트워크 또는 서버로 전송하지 않아요. 건강 정보를 광고에 사용하지 않으며, 계정·로그인·광고·인앱 구매가 없어요. 앱은 의료 서비스나 의료 판단을 제공하지 않아요.

Apple Watch 운동 기록의 백그라운드 전달은 iOS와 기기 상태에 따라 지연될 수 있어요. 기록이 없다는 사실만으로 HealthKit 읽기 권한이 거부됐다고 판단하지 않아요.

백업·복원·공유

백업은 사용자가 직접 실행하고, 공유 창에서 선택한 위치에 파일로 저장해요. 백업 파일에는 건강 관련 러닝 기록과 운동 상세가 포함될 수 있어요. 앱은 파일을 자동으로 업로드하거나 외부 저장소에 보내지 않으며, 사용자가 선택한 대상에 공유할 때만 파일이 기기 밖으로 이동할 수 있어요.

공유 카드는 사용자가 저장 또는 공유 버튼을 눌렀을 때만 이미지 파일을 만들어요. 저장·공유 대상은 iOS 공유 창에서 사용자가 선택해요.

삭제와 보관 기간

앱을 삭제하면 앱 내부의 로컬 데이터가 삭제돼요. 운영체제 백업, 사용자가 내보낸 JSON 백업 파일, 사진 보관함에 저장한 공유 카드는 앱 삭제와 별개로 남을 수 있으므로 해당 위치에서 사용자가 직접 관리해 주세요.

앱은 서버 계정을 만들지 않으므로 서버에 보관되는 사용자 건강 데이터가 없어요. HealthKit 원본 기록은 Apple의 건강 앱 정책과 사용자의 기기 설정에 따라 관리돼요.
